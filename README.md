# ☀️ My Weather App

Welcome to **My Weather App**! 🌦️ This project is a simple yet powerful weather application built with modern web technologies. It provides real-time weather data, forecasts, and a user-friendly interface to help you stay updated on the latest weather conditions.

![Project Screenshot](your-image-url-here)

## 🌍 Features

✅ **Real-time Weather Updates** – Get instant access to current weather conditions worldwide.  
✅ **5-Day Forecast** – Plan ahead with detailed weather predictions.  
✅ **Search by Location** – Easily find weather data for any city or region.  
✅ **Favorites Management** – Save your preferred locations for quick access.  
✅ **Unit Switching** – Toggle between Celsius and Fahrenheit.  
✅ **Beautiful UI** – A clean and intuitive interface designed for a seamless user experience.

## 🛠️ Tech Stack

- **Frontend:** React, Redux Toolkit, CSS
- **Backend:** Node.js
- **API:** AccuWeather API
- **State Management:** Redux

## 🔧 Configuration

To fetch weather data, you need an API key from **AccuWeather**.

1. Sign up at [AccuWeather API](https://developer.accuweather.com/).
2. Get your API key.
3. Create a `.env` file in the root directory and add:
   ```env
   REACT_APP_WEATHER_API_KEY=your_api_key_here
   ```
